## Typography — Geist + Geist Mono

- **Display + body:** Geist
- **Mono (numbers, addresses, tx hashes, grid math):** Geist Mono

Already wired via `next/font/google` in `app/layout.tsx` (variables `--font-geist-sans`, `--font-geist-mono`, mapped to `font-sans`/`font-mono` utilities in `app/globals.css`). Self-hosted at build time — never replace with a naive `<link>` tag.

Chosen deliberately for a terminal-grade desk: sharp geometry at 12–14px UI sizes, tight tabular numerals for margin math. Not a default — it was selected over Inter, IBM Plex, Manrope, Space Grotesk, and Instrument Serif from a rendered preview.

| Role | Class | Use |

## Tone and voice

### Words to use

Direct, specific, number-forward, factual. Every number carries its unit (`$128,450.00 USDC`, `1.42 health`, `+$6.02/day`). Prefer verbs over adjectives. Describe actions by what they do: "Draw on the line", "Repay". State caps and failures plainly: "3 draws per 12 h", "earning but locked", "redemption capped".

### Words to avoid

Banned (CI-enforced, from Agent.md §0.5): "risk-free", "guaranteed", "unhackable", "can't lose", "certainly profitable", "little/no risk", "yield guaranteed". Also: "yield" without "accrual", "bank-grade", "compliance-safe", "solves liquidations", "we're the only…", marketing superlatives, hype words, emojis, exclamation marks. This is a credit product — credibility wording is load-bearing.

### Voice example

> "Borrowing power $128,450.00 USDC — fee credit + coupon accrual, 10% cap applied. Treasury leg earns but stays locked: redemption is capped at $25,000,000 per investor per day."

## Usage dos and don'ts

**Do:**

- Use the CSS variables (`bg-background`, `text-foreground`, `bg-primary`) everywhere. Never hardcode hex in components.
- Keep the 4 px spacing grid (`gap-2`, `p-4`, `px-6`) — Workstation Dense: compact 4–8–12px paddings, panels delineated by borders, not shadows.
- Default to dark (`<html class="dark">`); light mode must still work everywhere.
- Use `font-mono tabular-nums` for any number that updates in place.
- Keep the persistent "Non-custodial · Aqua virtual balance" badge in the product chrome.
- Test every component in both modes before considering it done.

**Don't:**

- Hardcode colors or write `#0A0A0A`-style literals in component files.
- Use `transition-all` — always specify `transition-colors`, `transition-transform`, etc.
- Add decorative animation: motion is functional (state changes, data updates ≤150ms), fast, no bounce, no `ease` default — use `cubic-bezier(0.23, 1, 0.32, 1)`.
- Center-align data columns; tables are left-text / right-numbers.
- Override tokens per-component — fix values once in `globals.css`.
